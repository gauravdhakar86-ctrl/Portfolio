PORTFOLIO WITH WORKS & PROJECT GALLERY

Files:
- index.html: updated portfolio page
- images/works/: the five project screenshots used by the gallery

To publish on GitHub Pages:
1. Upload index.html to the root of your PORTFOLIO repository (keep the filename exactly index.html).
2. Upload the entire images/works/ folder, preserving the folder structure.
3. Commit the changes and refresh the published site.

The gallery is inserted after “Projects & Practical Labs”. Clicking a screenshot opens a larger preview; press Escape or click the dark background to close it.

Note: The profile photo currently references a separate local image filename from the original HTML. Upload that photo alongside index.html if you want it to display on the hosted site, or use the profile-photo upload control in the page.
